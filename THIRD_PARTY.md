# Third-party dependencies and license review

This inventory covers the bundled Rust decoder and a snapshot of the resolved
Flutter/Dart package graph. The Rust source archive contains the locked crate
sources, their license files and build instructions. Flutter SDKs, AndroidX
CameraX and other platform dependencies are resolved separately by the host
application; their exact versions and notices depend on the host build.

## Status and remaining checks

- The current hook uses `code_assets` and `hooks` to select precompiled
  binaries. The current binaries were rebuilt directly with Cargo using the
  script supplied in the source archive.
- The current Android camera implementation declares camera, microphone and
  legacy storage permissions in its manifest; the manifest merger can also add
  legacy read access implicitly. The scanner disables audio, but
  host applications must review their merged manifest and remove permissions
  they do not need; the example demonstrates this removal.
- Preserve the notices and license texts for the decoder sources and binaries
  when redistributing them. Source and license files for locked Rust crates are
  also included in `native/decoder-source.tar.gz`.
- Host applications should review their resolved AndroidX CameraX, Gradle,
  iOS and Flutter SDK dependencies and their own attribution obligations.
- Previous decoder builds on the same machine produced identical Android
  outputs; iOS outputs differed. Those results do not establish the
  reproducibility of subsequently rebuilt binaries. Independent reproduction
  and device testing of the current binaries remain outstanding.

## Native link audit and corresponding source limits

For the previous decoder binaries, link maps were generated by rebuilding the vendored source using the documented
Rust and platform toolchains. All three Android rebuilds matched the distributed
binary hashes. Their maps include Rust standard-library components and object
files from the NDK's static `libunwind.a`, in addition to decoder crates. The
three iOS rebuilds produced maps but differed in hash from the shipped binaries;
the maps therefore describe those rebuilds, not proven byte-identical copies of
the shipped iOS artifacts. Optimization and inlining mean the map's archive
names alone are not a complete inventory of source-level contributions. Keep
all crate notices, including the source-level copyright inventories for moxcms
and pxfm, rather than only notices for names visible in a link map.

The Rust compiler identifies its source as [commit 1159e78c4747b02ef996e55082b704c09b970588](https://github.com/rust-lang/rust/tree/1159e78c4747b02ef996e55082b704c09b970588); Rust also distributes a [1.90.0 source archive](https://static.rust-lang.org/dist/rustc-1.90.0-src.tar.xz).
The NDK toolchain identifies [LLVM base revision 3b5e7c83a6e226d5bd7ed2e9b67449b64812074c](https://github.com/llvm/llvm-project/tree/3b5e7c83a6e226d5bd7ed2e9b67449b64812074c)
and Android's [patch set](https://android.googlesource.com/toolchain/llvm_android/+/e727bfb014bd436f581a66a450c939a6983a1fc3/patches/).
The official Rust source archive was reachable when checked. The toolchain's
`clang_source_info.md` identifies the LLVM base and Android patch set above;
these are upstream references, not copies hosted in this package. The bundled
source archive contains the locked decoder crates, their licenses, the decoder
source, headers and rebuild script; it does not contain the full Rust or LLVM
toolchain sources.

Rust states that its standard library is generally MIT OR Apache-2.0, with
third-party exceptions detailed in the distributed Rust copyright inventory.
LLVM's libunwind is generally Apache-2.0 WITH LLVM-exception; its original
license and third-party notices are included in the NDK notice bundle. Preserve
all applicable notices when redistributing the decoder. The LLVM exception's
terms for embedded object code are distinct from GPLv3's System Libraries
exclusion. GPLv3 excludes qualifying System Libraries and generally available
unmodified build tools from Corresponding Source; whether a particular bundled
runtime qualifies depends on the license definition and the distribution.
The upstream links above also help recipients locate the sources. If relying on
GPLv3 section 6(d) for any required source hosted elsewhere, maintain clear
instructions and availability as that section requires. This is a practical
inventory and does not establish a legal determination for every component.

## Native toolchain notices

The decoder binaries include code from the Rust standard library. The original
Rust 1.90.0 standard-library attribution inventory is provided at
`third_party_licenses/rust-toolchain-1.90.0/COPYRIGHT-library.html`, together
with the license texts shipped by that toolchain in its `licenses/` directory.
The inventory covers the standard-library release and its build dependencies;
it is broader than a list of code proven to be present in each decoder.

The Android libraries were linked using Android NDK 28.2.13676358. The NDK's
original `NOTICE` and `NOTICE.toolchain` files are preserved in
`third_party_licenses/android-ndk-28.2.13676358/`. These cover the NDK and
toolchain as a whole, including tools and components not necessarily included
in the decoder binaries; inclusion of a notice does not mean that its license
applies to every binary. The Android link maps identify static `libunwind` objects; the NDK notices
cover more than the components shown by these maps.

License texts and attribution notices must travel with redistributed binaries
as required by the applicable licenses. The sources of the separately supplied
Flutter SDK, Android system libraries, and host app dependencies are not
included in this package; their distributors and app developers should review
the notices and obligations applicable to their distributions.

Sources: [Rust licensing](https://rustc-dev-guide.rust-lang.org/licenses.html), [LLVM libunwind license](https://github.com/llvm/llvm-project/blob/3b5e7c83a6e226d5bd7ed2e9b67449b64812074c/libunwind/LICENSE.TXT), [GPLv3 text](https://www.gnu.org/licenses/gpl-3.0.html), [rqrr manifest](https://docs.rs/crate/rqrr/0.11.0/source/Cargo.toml), [Flutter camera](https://pub.dev/packages/camera/versions/0.12.2), [GNU license compatibility](https://www.gnu.org/licenses/license-compatibility.en.html), [GNU license list](https://www.gnu.org/licenses/license-list.html).
